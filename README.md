## How to install/use

#### 1.Clone repository

```bash

git clone https://github.com/MisterRadhoo/FakeStoreApi_26.git

```

#### 2.Go to project directory

```bash

cd backend

```

#### 3.Install dependencies

```bash

npm install

```

#### 4.Use mockData for testing purposes (Optional)

```bash

cd src/mockData
node seeder.js -i  

```
**or**

```bash

node seeder.js -d 

```

#### 5.Start server (CLI)

```bash

 nodemon src/index.js

````

**or**

```bash

npm run dev

```
